# 163braces 資訊站

收藏台灣歌手 **163braces** 演出、歌單與歌詞的非官方粉絲網站。

👉 <https://163braces.info>（英文版：<https://163braces.info/en/>）

想知道 163braces 最近在哪裡演出、某一場唱了哪些歌、某首歌的歌詞和翻譯，或是自己追過哪些場次，都可以在這裡找到。資料由粉絲一起整理，歡迎補充。

---

## 首頁

- **即將演出**：接下來的幾場演出，一眼看到日期和地點。
- **最近常唱**：最近幾場演出裡，每首歌出現的比例。
- **隨機聆聽**：隨機播一首歌的影片，旁邊附上歌詞。
- **粉絲留言**：跑馬燈上是粉絲想對 163braces 說的話，登入後也可以留一句。

## 演出

- **演出列表**：歷年所有演出，可以用關鍵字、城市、類型、日期篩選，也能直接點台灣地圖上的縣市。有歌單的場次點一下就能展開。
- **演出統計**：各年份、各月份、各類型的演出場次圖表，以及每年在各縣市的演出地圖。
- **歌單統計**：歌單收集進度、每首歌的累積演出次數、各類型每場唱幾首，還有「演出機率對照表」：比較每首歌在最近幾場和全部場次的出現機率，看出最近哪些歌比較常唱、哪些歌很久沒出現。
- **年度回顧**：選出你最喜歡的歌、你去過的場次，再寫一段想說的話，網站會幫你做成一張回顧卡片，可以下載分享。卡片在你的瀏覽器裡製作，內容不會傳到網站。

## 歌詞

- 依專輯整理，點專輯名稱展開曲目。
- 可以只看中文、看中英對照，對唱的歌也可以分開兩位歌手的部分。
- 每首歌會列出唱過幾次、最近一次在哪一場演出，以及相關影片。
- 曲名後面有「🎼 樂譜」的，代表有粉絲分享的樂譜。

## 樂譜

粉絲自己採的譜，經過審核才會公開。每份樂譜都有自己的頁面，可以看圖檔、文字譜和演奏影片，也可以按讚。

這些都是非官方版本。權利人如果需要下架，請來信，我們會盡快處理。

## 文章

站務公告、粉絲專頁與社群介紹等。

## 用 Google 登入之後

不登入也能瀏覽全部內容。登入之後可以：

- **我去過**：在演出列表標記自己去過的場次，「我的足跡」會整理成統計和地圖。
- **喜歡的歌**：在歌詞頁或歌詞索引按 ♥，在「我的」裡自己排出喜歡的順序。
- **公開個人頁**：想分享的話，可以打開自己的個人頁，讓別人看到你去過的場次和喜歡的歌；預設是不公開的。
- **投稿**：
  - **粉絲留言**：送出馬上出現在首頁跑馬燈，之後也可以自己刪除。
  - **樂譜**：審核後公開；送出後還能修改（修改也要再審核），不想公開了可以要求刪除。
  - **歌單**：替已經有的演出補上或修正歌單。
  - **新增演出資訊**：網站上還沒有的演出（例如剛公布的場次），也可以順便附上歌單。

  歌單和演出資訊經過管理者確認才會更新。每一筆投稿的審核狀態，都可以在「我的 → 我的投稿」看到。

粉絲留言和樂譜每次都可以自己選擇署名方式，也可以匿名。

## 隱私

網站會收集哪些資料、怎麼使用、誰看得到，請看[隱私權政策](https://163braces.info/privacy/)。在「我的 → 設定」可以隨時刪除帳號，你的紀錄和投稿會一起刪除。
